# Chatwoot

**Site Oficial:** [https://www.chatwoot.com/](https://www.chatwoot.com/)

## O que é?
Chatwoot é uma plataforma open-source de engajamento de clientes que oferece suporte a diversos canais, como chat ao vivo, e-mail e redes sociais.

How to run:

```bash
cd ./chatwoot && npm run dev
```
