# Videogen

## Como usar

Execute `npm run dev` para levantar o serviço, depois execute `npm run hyperframes` para se conectar ao Hyperframes. Então basta iniciar um projeto `npx hyperframes init my-video` e acessar http://localhost:3000 para ver o preview em tempo real.

Para editar o arquivo "source" do video, basta pedir para a IA editar o `videogen/hyperframes/my-video/index.html` com a ajuda do `videogen/hyperframes/my-video/AGENTS.md`.
